This file is a concise compliance checklist for multilingual README maintenance.

## Canonical source

- [README.md](README.md) is the canonical source of truth.

## Tracked README set

- [README.md](README.md)

## Compliance checklist

- [x] Canonical source is defined and used consistently.
- [x] All current README language files are known and tracked.
- [x] README language files are expected to be updated together for significant user-visible changes.
- [x] Major sections and overall structure are aligned across language variants.
- [x] Diagram presence and SVG fallback links are aligned across language variants.
- [x] External evidence links for tooling claims are aligned across language variants.
- [x] Implemented-state checklist is aligned across language variants.
- [x] Roadmap and TODO checklist states are aligned across language variants.
- [x] Cross-references point to [AGENTS.md](AGENTS.md) as the governance document.
- [x] New-language onboarding process is defined in [AGENTS.md](AGENTS.md).

## Update rule

Update this checklist whenever multilingual README semantics, tracked language files, or governance references change.
